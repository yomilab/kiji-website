# Yomi RSS Reader Website

Public website for [Yomi Reader](https://github.com/yomilab/yomi-rss-reader) — a local, modern RSS reader for macOS, Windows, and Linux.

**Features:** stations, reader mode, 13 reader themes, AI assistant access (MCP), Manage Feeds, Markdown sync, and background refresh. All data stays on your device.

## Development

```bash
npm install
npm run dev
npm run build
npm run preview
```
